## 🏛️ Application Architecture

```
src/
  components/
    Navbar.tsx        # Responsive sticky glassmorphism navigation with telemetry logo
    Hero.tsx          # Full-screen hero with 3D gyroscopic developer artifact & CTAs
    About.tsx         # Verified developer biography, principles & academic foundation
    TechStack.tsx     # Interactive MERN tier explorer (Mongo, Express, React, Node, Socket.io)
    Projects.tsx      # Flagship case studies with deep-dive architectural modal blueprints
    Experience.tsx    # Verified internship timelines (Blackbucks Engineers & 1Stop.ai)
    Skills.tsx        # Comprehensive technical skill matrix across full-stack domains
    Education.tsx     # Academic credentials, scores & professional certifications
    Resume.tsx        # Local PDF download trigger with interactive document viewer
    Contact.tsx       # Direct mailto transmission, clipboard copy & response SLA
    Footer.tsx        # Architectural credits, back-to-top button & copyright
    Scene3D.tsx       # Metallic Three.js gyroscopic core with cursor parallax & fallbacks
    Icons.tsx         # Brand SVGs (GitHub, LinkedIn, MongoDB, Express, React, Node)
  hooks/
    useLenis.ts       # Hardware-accelerated smooth scrolling with reduced-motion check
    useActiveSection.ts # Viewport scroll watcher for active navbar link state
  data/
    profile.ts        # Verified personal info, philosophy & quick metrics
    projects.ts       # Complete schema, architecture & workflows for 3 flagship apps
    experience.ts     # Verified internship roles, responsibilities & highlights
    skills.ts         # Full skill categorizations with project usage tags
    education.ts      # B.Tech, Class XII, Class X details & certifications
  utils/
    confetti.ts       # Canvas particle burst celebration on resume download & contact
  App.tsx             # Root application orchestrator
  index.css           # Tailwind v4 theme, metallic badges & ambient glow utilities
  main.tsx            # React 19 entry point
```
